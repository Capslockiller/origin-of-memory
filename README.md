# Origin of Memory 2.0

A second brain for Claude Code that captures, compiles and retrieves memory as a **mechanism**,
not a habit — one self-contained Windows executable, no interpreter, no scripts.

**Status: rebuild in progress (2026-09-09).** `main` is the 2.0 line. The previous
Python/PowerShell mechanism (v0, last release [v0.7.0](https://github.com/Capslockiller/origin-of-memory/releases/tag/v0.7.0))
lives on branch [`v0`](https://github.com/Capslockiller/origin-of-memory/tree/v0) and stays readable as reference.

- Build contract: the owner's 2.0 spec (Turkish, kept in the owner's vault; published here when the first acceptance gate passes).
- `src/Oom/` — the exe. `tests/Oom.Tests/` — xUnit, scar tests first. `bench/` — Python gold-set tools (measurement only).
- Release history: [CHANGELOG.md](CHANGELOG.md), [docs/releases/](docs/releases/).
