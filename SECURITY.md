# Security

`oom` runs locally, reads Claude Code transcripts under your user profile, and calls only the `claude` CLI on the same machine. Every outbound prompt passes through a single egress gate.

## Reporting a vulnerability

Email odenastudio@gmail.com with the affected version, steps to reproduce and the impact. Do not open a public issue for security reports. You will get a reply within seven days.

## Supported versions

Only the latest release receives fixes.
